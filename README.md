                                                     Pizza Sales Dashboard 🍕

This project is a Power BI dashboard created to analyze pizza sales data and generate meaningful business insights.

## 📊 Dashboard Features
- Total Revenue Analysis
- Total Orders & Quantity Sold
- Top Selling Pizzas
- Category-wise Sales
- Daily & Monthly Trends
- KPI Cards and Visual Insights

## 🛠 Tools Used
- Power BI
- SQL
- Excel / CSV Dataset

## 📌 Key Insights
- Identified best-selling pizza categories
- Analyzed peak sales periods
- Compared revenue across pizza sizes and types
- Improved data visualization using interactive dashboards

## 📂 Files Included
- `Pizza DB Power BI.pbix` → Main Power BI Dashboard File

## 🚀 Project Purpose
This project was created to practice:
- Data Cleaning
- Data Visualization
- Business Intelligence Reporting
- Dashboard Design
